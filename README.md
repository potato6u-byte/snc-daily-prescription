# SNC 데일리 온도처방 (snc-daily-prescription)

신앙촌 발효유 **런(RUN) 공정**의 일일 온도 처방 도구입니다.
**전날(들)의 공정결과 값을 확인하고, 오늘의 온도처방을 자동 산출**합니다.

- 근거 자료: 부산 신앙촌 허브 · 「신앙촌 데이터 관리 컨설팅 최종 보고서」(2025.7~2026.7, 278배치) 및 FermaAX 작업
- 스택: Python 3.10+ / Streamlit / SQLite / pandas · openpyxl
- 배포 형태: 로컬 실행(태블릿·모바일 브라우저 접속 가능)

## 무엇을 하는가

```
[전날 실적 입력]  엑셀 업로드 또는 표 입력
        │
        ├─ 이송 열손실 잔차 = 실측 이송후온도 − 처방 예측
        │        └─ 최근 7일 EWMA → 오늘 살균냉각 설정 보정
        │
[오늘 환경 입력]  새벽 실내온도 · 외기 · 착수 시각 · 탱크 · 배치량
        │
        ▼
[오늘의 온도처방]  살균냉각 설정 / 핫워터 설정 / 목표 유입온도
                 예상 종결시간 · 산도차 · 열손실량 · 신뢰도
```

## 처방 산출 근거

| 항목 | 식 / 값 | 출처 |
|---|---|---|
| 이송 온도하락 | `ΔT = 2.44 − 0.078 × 새벽실내온도` (n=277, r²=0.61, p<0.001, 95% 예측범위 ±0.70℃) | 최종보고서 그림 10 / 표 1 |
| 살균냉각 설정 | `38.5 + ΔT + 잔차보정 + 시간대보정` | 기준선 38.5℃ |
| 골든 배치 | 핫워터 38.4℃ · 종결 380분 · 최종산도 0.965 · pH 4.70 · 점도 3,200 cP | FermaAX 제어 기준 |
| 기준선 | 핫워터·살균냉각 38.5℃, 외기 약 27.6℃ → 산도차 0.116 · 종결 382.9분 | 278배치 |
| 겨울 보정운전 이탈 | 살균냉각 +1.4~3.0℃ 상향 → 산도차 −9.6%, 종결 −19.0분 | 278배치 |
| 종결·산도 민감도 | −8.5 분/℃ · −0.0051 산도차/℃ (기준선 대비) | 겨울 이탈량 역산 |
| 핫워터 설정 | `38.4 + max(0, 25 − 실내온도) × 0.040 × κ + 시간대보정×0.7` | **현장 경험식(미검증)** |
| 시간대 보정 | 착수 시간대별 Δ℃ (22–06시 +0.3 등) | **현장 경험식(미검증)** |

> ⚠️ `핫워터 설정`과 `시간대 보정`은 아직 데이터로 규칙화되지 않은 경험식입니다(보고서 3단계 로드맵 대상).
> 앱의 처방 근거 표에 항목별로 미검증 여부가 함께 표시됩니다.

### 잔차 보정(피드백)
- 이송 잔차가 (+) ⇒ 실제 하락폭이 예측보다 컸음 ⇒ **오늘 살균냉각 설정을 상향**
- 최근 7일 EWMA(α=0.5)를 적용하며, UI에서 자동/수동 전환이 가능합니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py          # 또는 Windows: run.bat
```

기본 주소 `http://localhost:8501`, SQLite 파일은 `snc_prescription_history.db`에 생성됩니다.

## 화면 구성

1. **① 전날 공정결과 확인** — 엑셀 업로드 또는 표 직접 입력, 실적 이력, 처방예측 자동 연결
2. **② 오늘의 온도처방** — 환경 입력 → 처방 계산 → 근거 표 · 처방서(.xlsx) 내려받기
3. **③ 이력 · 통계** — 처방 이력, 예측 대비 실측 정확도 추이(ME / MAE / SD)

## 입력 양식

`examples/실적입력_예시.xlsx` 를 쓰거나, 앱의 **[실적 입력 양식 내려받기]** 버튼으로 받습니다.

| 열 | 필수 | 비고 |
|---|---|---|
| 일자 | ✓ | 처방이력과 매칭되어 예측값이 자동 연결됨 |
| 투입탱크 / 배치량(L) | | |
| 새벽 실내온도(℃) | ✓ | 회귀식 입력값 |
| 살균냉각 실측(℃) | ✓ | 토출 실측액온 |
| 이송후 탱크온도(℃) | ✓ | 이송 열손실의 종속값 |
| 종결시간(분) | ✓ | 잔차 산출 |
| 최종 산도 / pH / 점도 / 이슬분리 / 관능점수 | | 품질 추이 |
| 비고 | | |

영문 헤더, 여분의 공백, 빈 행, 안내 시트가 섞여 있어도 자동으로 처리합니다.

## 기상 연동

기장군(35.2447, 129.2226) 오픈메테오 예보를 연동해 현재 외기·오늘 최저/최고·**내일 새벽 외기 최저**를 표시합니다.
오늘 새벽 실내온도는 실측 입력이 원칙이며, 예보값은 참고(실내 = 외기 + 4℃)로만 제시합니다.

## 알려진 한계

- 이송 열손실 회귀는 **기록 간 평균적 관계**이며, 배관·이송시간·수량 조건은 반영되지 않습니다(보고서 한계 절).
- 새벽 실내온도 15.8℃ 미만은 관측 최저치 이하 외삽 구간으로, 처방 신뢰도가 **낮음**으로 표시됩니다.
- 최적 설정값의 인과 검증은 보고서 1~3단계(수집 표준화 → 모니터링 자동화 → 보정량 규칙화)에서 축적되는 데이터로 확정해야 합니다.
- 온도 설정의 인과 효과·규격 적합성 판정은 본 도구의 범위가 아닙니다.
